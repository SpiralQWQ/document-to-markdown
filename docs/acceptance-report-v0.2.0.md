## 三、穷举测试发现的 Bug（2 个，均已修复）

| # | Bug | 根因 | 修复 |
|---|-----|------|------|
| 1 | export_md 全部导出失败（"Pandoc 不存在"）| 重构后 paths.py 默认 PANDOC 只找 PATH，便携版 pandoc 不在 PATH | paths.py 加 `_detect_pandoc()`：环境变量 → 便携版 → PATH 三级检测 |
| 2 | clean_hook 运行中改环境变量不生效 | CLEANER_PATH 在模块加载时固化 | 改为 `_cleaner_path()` 函数每次实时读环境变量 |

> 修复后均重新跑通该 Task 全部穷举用例 + 4 轮审核。
